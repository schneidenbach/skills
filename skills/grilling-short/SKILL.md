---
name: grilling-short
description: Interview the user relentlessly about a plan or design, but wants the session to be condensed. Use when the user wants to stress-test a plan before building, or uses any 'grill' trigger phrases.
---

Interview me relentlessly about every aspect of this plan until we reach a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions. For each question, provide your recommended answer.

Ask multiple questions at once to allow the user to make multiple simultaneous decisions. Continue to ask a series of questions until you and the user are satisfied with the desired outcome.

If a question can be answered by exploring the codebase, explore the codebase instead.
